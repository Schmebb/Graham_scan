        Helper functions
        

          
Each point is { x, y } with y pointing up. Return the hull as an array of points in boundary order. Each helper call becomes one step in the animation.

          
pivot(p)Mark the starting point (lowest y, then lowest x).

          
sortOrder(arr)Show the sorted order as numbers next to each point.

          
consider(p)Highlight the point you are about to process.

          
cross(o, a, b)Returns (a−o)×(b−o) and draws the turn. Positive is a left (counter-clockwise) turn.

          
show(stack)Draw the current stack as the hull in progress.

          
log(...values)Print a message in the step caption.

          
Use your own math (for example Math.atan2) inside the sort comparator, since every cross() call adds a step. Code runs in a sandbox and stops after 3 seconds.
